Public Housing and Grocery Access in New York City

How To Use

  • Start with Borough, Search Development, and Highlight Max Distance to focus the map.
  • Choose Nearest Store Mode to compare access to the closest grocery point versus the closest full supermarket.
  • Click any NYCHA development to update the Selected Development card and automatically set that site as Development A in the comparison panel.
  • Use Compare Two Developments to pick two sites and review side-by-side grocery distance and 4-item staple basket differences.
  • Use the Staple Price Chart panel (right side, under Selected Development) to load live ZIP-based prices or apply manual CSV prices.
  • Use Include FHA Repossessed Groups, Show Mapped Store Points, Clear Selected NYCHA, and Reset View as needed.

How To Use The Data

  • Use distance and neighborhood demographics together to identify developments with higher food-access pressure.
  • Average 4-item price values reflect standardized units: eggs (12 ct), milk (1 gal), bread (20 oz), and chicken (1 lb).
  • Price fields may use loaded live/manual values when available, otherwise modeled estimates are used and labeled in the dashboard.
  • Income and race are ACS neighborhood context values and should not be interpreted as direct NYCHA resident-level household data.
  • Distance values are straight-line estimates from development footprints to mapped stores, not walking-route travel times.

About This Dashboard And Data

This dashboard shows where NYCHA developments are located, the nearest grocery option to each site, and how access and staple food prices compare across neighborhoods.

Data Snapshot: Base map data reflects files prepared on May 12-15, 2026. Grocery price values can update live when you load prices by ZIP code.

How Staple Price Is Calculated: The 4-item average is the mean price of eggs (12 count), milk (1 gallon), bread (20 oz), and chicken (1 lb). If you do not load prices, the dashboard uses modeled estimates.

How Price Summary Cards Work: Filter and city price cards are based on unique nearest stores, so one store is not counted multiple times just because it serves several developments.

Store Mode: You can switch between the closest grocery point and the closest full supermarket. Supermarket mode excludes smaller non-supermarket listings.

Distance Method: Distance is shown as straight-line miles from each development area to the nearest mapped store in the selected mode. It is not a walking-route distance.

Income and Race Caveat: Park and open-space areas (for example Central Park) are shown as limited-data zones, so race and income are not displayed there. Some non-park areas may still show N/A if no published value is available for the selected ACS period.

COVID Data Note: The current income and race layer uses ACS 2020-2024 estimates. That period includes COVID-era years, so some neighborhood values may reflect pandemic-related economic and demographic shifts.

Sources

Source 1 - NYCHA Development Boundaries: NYC Open Data - NYCHA Public Housing Developments (phvi-damg).

Source 2 - Grocery Store Locations: NYS Open Data - Retail Food Stores (9a8c-vfzj), filtered to grocery and supermarket records.

Source 3 - Neighborhood Income and Race: U.S. Census ACS 2020-2024 Table B19013 (Median Household Income) and U.S. Census ACS 2020-2024 Table B02001 (Race). Neighborhood-level backup for missing tract income: income_change_nta_summary_arcgis.csv.

Source 4 - Official NYCHA System Counts: NYCHA About Page and NYCHA-reported context used in this dashboard (243 conventional developments, 152,926 apartments, 92 PACT, 335 total developments).
