# My College Launchpad — Student-Forward Multilingual Prototype

This version is designed for undocumented and immigrant students preparing for college.

## Pages
- `index.html` — student entry points
- `college-list.html` — searchable college list builder and comparison
- `my-plan.html` — personal action plan connected to the saved college list
- `college-journey.html` — interactive timeline
- `paying-for-college.html` — student financial-planning guide
- `about.html` — project purpose, privacy, and prototype notice

## Languages
English, Spanish, Simplified Chinese, Bangla, Haitian Creole, and Korean.

## Privacy
The prototype does not request a name, address, or immigration status. Saved information remains in the browser on the device being used.
