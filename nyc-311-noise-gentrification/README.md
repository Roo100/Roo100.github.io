# NYC 311 Noise Complaint Visualizer

Open `index.html` in a browser to view a live visualizer for 311 noise complaints across the five NYC boroughs.

The page pulls:

- NYC Open Data 311 Service Requests from 2020 to Present: `erm2-nwe9`
- Census Reporter ACS county indicators for population, income, poverty, rent, tenure, and race

The pressure score is an exploratory index, not a causal model. It combines selected 311 noise complaint rate, poverty rate, renter share, people-of-color share, and median rent to identify boroughs where enforcement attention and displacement vulnerability may overlap. For a research paper, use this as a starting visualization and follow up with tract, NTA, or neighborhood-level analysis.
